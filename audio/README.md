# WhiteNoiseChoir Audio Library — Public Beta

20 original digitally synthesized audio tracks, not recordings taken from YouTube.
All files are generated by `scripts/generate_audio.py` and committed automatically.

- Output: MP3, mono, 44.1 kHz, 112 kb/s
- Duration: approximately 72 seconds per source track
- Playback: browser audio element in a seamless repeat mode
- Sound-mix presets: built in `index.html`
- Synthetic fan, rain, sea and other ambience sounds are simulated, not field recordings
- Quality assurance: listening and mobile background playback require testing on real devices

Do not claim therapeutic or medical outcomes. Keep listening volume modest.
