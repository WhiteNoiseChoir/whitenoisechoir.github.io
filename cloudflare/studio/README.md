# WhiteNoiseChoir Studio Worker

The English homepage is the public audio-only mixer. The public and signed-in Vietnamese editors use one R2 inventory snapshot. The public editor verifies browsers with Turnstile for protected media requests. Deploy the Worker only after preparing access and storage.

1. In Cloudflare Zero Trust, create a self-hosted Access application for `whitenoisechoir.com/vi` and `whitenoisechoir.com/vi/*`. Allow the owner's email and enable One-time PIN or the owner's existing identity provider. Set the exact team hostname, application audience and allowed owner email in Wrangler's `ACCESS_TEAM_DOMAIN`, `ACCESS_AUD` and `STUDIO_OWNER_EMAILS`. The Worker validates the Access signature, audience and email.
2. Create the private R2 bucket `whitenoisechoir-studio-state`. Keep public URLs disabled for it. Bind it as `STUDIO_STATE` and bind `whitenoisechoir-media` as `MEDIA`. Allow the existing catalog workflow's R2 credentials to write the new bucket, then set the repository Actions variable `STUDIO_STATE_BUCKET` to that name and run the Studio asset catalog workflow. The owner catalog, public audio metadata and private media lookup shards use separate keys.
3. Set the Worker's `TURNSTILE_SECRET_KEY` from the site's existing widget. Keep `PUBLIC_CATALOG_ENABLED` false at the first deployment. Make sure the zone is proxied and apply the supplied Worker routes, including the direct media prefix blocks. Disable any public R2 alias that bypasses the block. Keep the legacy `/audio/` prefix reachable.
4. Check a signed-out `/vi/` and a signed-out trial URL. Verify the owner can sign in, open the Cabin trial, and save a new private draft. Confirm a known direct `/asset-library/` URL cannot serve its object and the Worker rejects anonymous source requests. Enable `PUBLIC_CATALOG_ENABLED` only after these checks, then verify one normal Turnstile session can preview a WAV, add it to the public timeline and render audio. Verify the same source is visible in the signed-in Vietnamese Studio.
5. To publish a saved mix, select **Public**, choose the finished MP3, WAV, M4A or MP4, and confirm. The approved media is streamed into the private bucket and becomes visible in `/library/` only once the release record is saved. Public viewers never receive the editable project. The upload uses one HTTP request and is subject to the Cloudflare plan's request body size limit.

Never paste secrets into the repository. This branch changes the GitHub Pages VI fallback to a sign-in landing page. Merge it only after the owner sign-in Worker is provisioned. Earlier public preset data is still visible in repository history; store new private draft data through the authenticated Studio editor. For a ChatGPT-created mix, import the project JSON in the signed-in editor and use Lưu bản thử to make its private /vi/<slug>/ route. Public remains an explicit action for a selected finished file.
